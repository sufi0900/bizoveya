Missing recorder setup disables the buttons without exposing values.

Each exact attempt retains one claim UUID after a lost response; same-claim active retry can finish, terminal retry uses guarded finish without another claim or packet. Foreign active leases are blocked; expired claims use existing055 recovery. Refresh shows recorded state and never creates receipt. Completed packets stay terminal. Unknown/conflicting completion requires inspection, never an automatic blind retry. Queue visibility is bounded to the latest100 own invitation batches; older history remains retained in the Founder desk.
