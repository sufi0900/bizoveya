## Implemented source

Server-only admin media contracts separate `image` and `live-voice` capabilities. Model IDs are validated configurable values rather than shared with text bindings. Provider selection allows Gemini or a future OpenAI adapter; selecting an uninstalled adapter fails clearly. Disabling artwork leaves core agency capabilities available.

The Gemini image adapter makes exactly one fixed-origin, redirect-rejecting request with a20-second timeout, bounded prompt and1K/aspect-ratio selection. It bounds streamed response bytes, requires one completed candidate and one PNG/JPEG, validates canonical base64 and image signature, and returns provider/model provenance and truthful usage. Missing usage is null, never zero. Full decode/sanitization/rights review must precede durable media storage; this transport does not label generated bytes as user uploads or save them automatically.

The Gemini Live adapter provisions one-use ephemeral tokens with a30-second new-session window and120-second expiry, pinned model and server instruction constraints, audio replies and input/output transcription. It exposes no standard API key, no save/publish/approval tools and no autonomous agency command authority. Transcripts must enter the existing correction/confirmation flow.

Neither transport is connected to an HTTP endpoint or worker yet. No provider call, hosted migration, environment setting change, generation or publication occurred. Token provisioning remains a provider operation and must receive durable admission before activation.
