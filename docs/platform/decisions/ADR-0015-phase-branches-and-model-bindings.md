# ADR-0015: Phase branches and reviewed model assignments

Date2026-10-03 PKT. Accepted design; source delivered; founder acceptance pending.

Use one branch/PR per phase and durable continuation checkpoints. Schedule remains paused until GitHub writes work. Assignments pin reviewed agent, model profile, credential reference and successful matching test; require matching routing tier and evidence within24 hours. Changes invalidate qualification. Assignment is configuration, not execution authority or spend enforcement. Keep public/admin deployments separate. Spending controls and durable drafts are separate next subphases. This record is a living decision and may be superseded explicitly with history retained.
