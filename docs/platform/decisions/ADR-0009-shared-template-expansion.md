# ADR-0009 — Shared business template expansion

Status: adopted for1.12/P02.4 source; founder acceptance pending.

Owner authorized continuation while on mobile and deferred all manual checks. Expand to six visual families through the existing catalog/schema/section renderer, shared template page composition and025 accepted IDs. Preserve existing URLs/drafts/history/publication boundaries and use one cumulative manual checklist. Three new family choices are adjustable implementation design proposals, not surveyed demand claims.

Distinct CSS/artwork provides actual stylistic differentiation; avoid three cloned vertical builders or decorative buttons implying booking/payments/LMS. Future schema/ID changes must synchronize validators, public compatibility, routes, previews, tests and docs. Agent template knowledge will consume catalog IDs/version when agents exist; do not claim a current agent update. Manual/local proof stays distinct. No time estimate or automatic phase acceptance.
