# ADR-0011 — Preview-only agent configuration before live runtime

Status: implemented source in1.14; hosted/founder acceptance pending. Living decision, revisable by later founder instructions.

The founder authorized continued work while performing deferred manual testing. P04 configuration follows private approved knowledge. Original P04.1 includes broader model/secret design; this delivery deliberately implements only configurable rules and site readiness. Provider-specific SDK qualificationP04.0 is deferred, not completed or removed.

Use a shared role contract, additive027 private immutable agent versions/review events, current MFA/grant RPCs and a human-approved preview pointer. Separate site preferences and current approved knowledge are assembled by a tenant-gated backend. Platform instructions are not returned to customer catalog/context. All tools remain inert declared capability names. Models/keys are not connected and runtimeEnabled is false.

Checks validate schema and declared capabilities only. Approval explicitly permits a context preview; it is not live activation/model evaluation. New drafts do not inherit checks; existing preview stays pinned. Human rollback selects a previously checked immutable version. Current admin alone never gains private tenant access. Bound16 definitions/200 versions; review/revoke unaffected by version cap.

Benefits: rules become editable without redeploying code while execution remains a separate accountable decision. Costs: no task result or qualifying hackathon model trace yet; provider/credentials/evaluations/runtime still needed. New agent kinds/capabilities remain code and permission changes. Latest preference version only retained; previews transient. Both app deployment roots now require the shared packages/ tree.

Affected: requirements/routes/architecture/data/agents/security/admin/dependencies/phases/manual/deployment/docs/evidence,32 and30. See19 for downstream change impact. All previously deferred founder/hosted gates remain pending until specific evidence.
