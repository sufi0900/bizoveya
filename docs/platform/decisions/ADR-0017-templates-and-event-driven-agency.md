# ADR-0017: reusable templates and event-driven digital agency

Date: 2026-10-08 PKT. Status: accepted planning direction; implementation staged and unimplemented beyond existing visual composer. Source: founder discussions and documentation instruction in [50](../50_EVOLUTION_TEMPLATES_AND_VISUAL_AGENCY.md).

## Context

Founder liked tested visuals and wants commercial variety, private AI-created reusable templates, voice-led agency coordination, hireable/custom specialists, real-time cartoon rooms, QA queues, recovery and broadcast meetings. Existing06 already defines facilitated meetings and safe interrupts; this decision extends it rather than replacing the run/budget/access contracts.

## Decision

Separate template definitions, immutable saved artifact versions and original artwork. Use a small shared catalog and personal-by-default templates with explicit authorized scopes. AI template output is a validated design specification, never arbitrary executable code. Provider subscription access is optional and gated by actual eligibility/capability; it is not a prerequisite for deterministic graphics.

Persist tasks/events/decisions as the authoritative workflow. Voice and rooms are input/projection surfaces of the same enforcement layer. Broadcast announcements once; invoke bounded specialist reasoning only when useful. Agents join meetings at safe checkpoints. QA, founder approval and external publication/readback remain separate. Configure custom agents using allowed tools, evaluations and permissions rather than unrestricted generated code.

## Consequences and boundaries

More variety can be delivered before purchasing artwork generation. Private ownership, version pinning and deletion/export semantics add data work. Rooms require replay/reconnect/accessibility and truthful states. Meetings may reduce redundant calls but savings require measurement. Subscription integration presently lacks evidenced Bizoveya commercial authorization and supports no image generation on the documented preview route. Publishing stays deferred. Template selection/LinkedIn image is the next proposed slice; private reuse, media, assistant, meetings, voice, office and custom agents follow their documented dependencies.

No SQL, credentials, new agent, voice engine, template library or publishing capability is added by accepting this planning direction. Acceptance of founder's basic visual tests does not close unrelated negative/security/mobile or commercial-quality gates.
