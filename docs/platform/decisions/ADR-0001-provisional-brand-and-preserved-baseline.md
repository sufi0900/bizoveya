# ADR-0001: Provisional Bizoveya brand and preserved Voxfolio baseline

**Status:** Proposed working decision, 2026-09-29. **Owner:** Sufian Mustafa.

Context: Voxfolio V27.12 is a working portfolio-focused codebase. The new scope covers native business sites, existing-site connections and supervised AI operations. A broader commercial label is useful while product positioning develops.

Decision: use **Bizoveya** as a provisional commercial/documentation name and `bizoveya-platform` as the package folder. Keep historical Voxfolio release documents, source API names, existing slugs, database names and deployed routes intact until a tested migration/redirect plan is accepted. No logo, domain or trademark clearance is implied. Replace prior Sitevanta suggestion, which was found to conflict with a similar website-service name.

Consequences: docs use Bizoveya for proposed platform and Voxfolio for inherited product; search both terms during migration. If name changes, update the brand register, README, docs/index, handoff and public assets together, then record a successor ADR. This ADR does not authorize public rename, deployment or domain purchase.
