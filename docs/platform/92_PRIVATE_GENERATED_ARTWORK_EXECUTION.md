## Implemented source boundary

The existing creator-private Image library now shows **Optional AI artwork** only as an independent capability. When image qualification is absent, paused, expired or unconfigured, the interface says so and keeps uploads, templates, text drafts and meetings usable. A qualified owner supplies one prompt, alternative text and aspect ratio, confirms the exact request, and starts one private attempt. Loading the page never calls a provider.

The authenticated server checks current membership, ownership, qualification and server-only configuration before durable admission. A trusted service client claims the request and records `provider_started` immediately before exactly one Gemini `generateContent` request. It requests one IMAGE response at1K, applies a20-second transport timeout and bounded8MiB response parser, accepts exactly one completed PNG/JPEG candidate, verifies canonical base64, media signature and the5MiB byte ceiling, and never automatically retries Gemini. The long-lived API key never enters browser state, receipts or provenance.

Provider bytes are decoded and re-encoded through the existing Sharp limits: one page, PNG/JPEG only, at most4096 pixels per side and12million pixels, sRGB normalization, orientation application, metadata stripping and a hash over the sanitized bytes. The v2 descriptor stores only request ID, provider, model ID and SHA-256 prompt hash—never the prompt or credential. Generated rights remain explicitly unattested `provider-output` until the existing owner review records an immutable accepted/rejected decision.

Additives074–075 preserve the private `campaign-private-media` bucket and existing paths. A service-only generated-attempt record binds request/claim, sanitized descriptor, object path and truthful usage. Preparation occurs before Storage upload; commit atomically creates the private media version, records the artifact receipt and settles the media request. Repair075 performs the service-only no-record lookup before new admission: an unconfigured new request reserves nothing, while a lost-response replay can return its committed record after qualification pauses. A stored pending object is hash-checked and committed without another provider call. Missing/mismatched bytes fail the request and require a new reviewed request. Unknown usage stays unknown under the existing accounting contract; it is never invented as zero.

The generated result enters the same private inventory, authenticated byte route, immutable review UI and reviewed visual-composition selector as user uploads. It is not automatically attached to a campaign, shared, published or used to regenerate accepted text. Artwork failure affects only optional artwork.

Current Google documentation lists image generation for Gemini3.1 Flash Image and notes that generated images include SynthID. The founder screenshot proves AI Studio generation only; it does not prove this project's API access, quota, free-tier treatment or commercial terms. Current Supabase documentation confirms private-bucket access remains governed by access control and that service keys bypass Storage RLS, so this implementation keeps the service key server-only and exposes no browser Storage policy.
